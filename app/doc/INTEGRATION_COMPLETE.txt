🔄 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

BEFORE (Manual Mapping):
  User Input              Backend Format          Display
  "Bug/Error"        →    "BUG_ERROR"        →    "BUG_ERROR" ❌
  (Manual work, error prone)

AFTER (Automatic Mapping):
  User Input              Mapper               Backend Format
  "Bug/Error"        →    (automatic)    →    "BUG_ERROR"
  
  Backend Response        Mapper               Display
  "BUG_ERROR"        →    (automatic)    →    "Bug/Error" ✅

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Backend error "not one of the values accepted for Enum"
SOLUTION: You're not using API hooks. Make sure to use useCreateTicketMutation()
          which handles the conversion. Don't use fetch directly.

PROBLEM: UI shows "BUG_ERROR" instead of "Bug/Error"  
SOLUTION: Make sure data comes from API hooks that have transformResponse.
          If using plain fetch, use getCategoryForFrontend() manually.

PROBLEM: TypeScript type error on category
SOLUTION: Use frontend format: const cat: Category = "Bug/Error"
          Not: const cat: Category = "BUG_ERROR"
